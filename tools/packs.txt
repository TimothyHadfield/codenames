# Themed word packs (2026-10-28). Our own lists, family-friendly.
# A line "## id | Name | one-line description" starts a pack; the words follow, any spacing.
# Every word must be in GloVe 6B (300d and 50d) so the computer can clue and guess with it:
# tools/build_packs.py checks that, and writes data/packs.json + data/packs/<id>.bin.
# Optional 4th field "mix=N": pack words per board for that pack (default 8, PACK_MIX in js/engine.js).
# Words already on the base list reuse the base row; new ones get rows of their own.
# Changing a pack's words or order changes that pack's seeded boards (base boards never change).
