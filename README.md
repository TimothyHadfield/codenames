# Codenames

Play: https://timothyhadfield.github.io/codenames/

- **Table:** type the same code on two phones to get the same board; the spymaster's phone shows the key. Type a clue to see the odds of hitting the assassin or the other team.
- **Play:** against the computer (you guess, or you give clues), two teams with any seat a computer, Duet, or an online room with friends.
- **Links:** a map of how closely the board's words are linked.

Word links come from GloVe (Stanford NLP, Public Domain Dedication and License). Board words are this site's own list. Codenames is a game by Vlaada Chvátil, published by Czech Games Edition; this is an unofficial fan tool with no rulebook text or game art.

Tests: `node --test`
